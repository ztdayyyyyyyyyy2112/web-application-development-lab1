# Lab 3 — Guided React 19 Exercises

**Use this package to build the three exercises step by step with genuine atomic commits.**

1. Open `COMMIT_GUIDE.md`.
2. Run initial Git commit on the scaffold.
3. Execute `./scripts/apply-step.ps1 1` in PowerShell, review, and commit.
4. Repeat through step 7. `_stages/` contains code snapshots and is ignored by Git.
5. Run `npm install`, `npm run dev`, `npm run build` to verify.

The source files in this folder are intentionally incomplete until you apply the corresponding stages.
